## Commands

This project uses **FVM** (Flutter Version Manager) pinned to Flutter **3.41.6**. Prefix all Flutter commands with `fvm`:

```bash
# Analyze for errors and lint issues
fvm flutter analyze lib/

# Run the app
fvm flutter run

# Regenerate Freezed models + Hive adapters + injectable config (after model changes)
fvm dart run build_runner build --delete-conflicting-outputs

# Regenerate localization files (after editing lib/l10n/app_en.arb or app_ru.arb)
fvm flutter gen-l10n

# Rebuild native splash
fvm dart run flutter_native_splash:create

# Rebuild launcher icons
fvm dart run flutter_launcher_icons
```

There are no tests in this project.

## Architecture

### Data flow

```
Hive box  →  *LocalDatasource  →  *Repository  →  *Provider  →  Widgets
```

All Hive boxes are opened once in `main()` before `runApp`. Repositories read synchronously from already-open boxes (no `async` on reads). Providers hold in-memory state and call `notifyListeners()` after mutations. Widgets use `context.watch<Provider>()` / `context.read<Provider>()`.

### Dependency injection

`get_it` + `injectable`. All datasources, repositories, and `ExportService` are annotated `@lazySingleton`. After adding a new injectable class, run `build_runner` to regenerate `lib/di/injection.config.dart`. Do **not** hand-edit that file. Retrieve singletons outside the widget tree with `getIt<T>()`.

### Providers (ChangeNotifier, no dispose needed in shell)

| Provider | Responsibility |
|---|---|
| `TransactionProvider` | All transactions + period filter + month navigation. Holds a reference to `ReportsProvider` so mutations auto-refresh charts. |
| `ReportsProvider` | Pie slices + bar chart groups derived from transactions. Stateless computation — call `load()` to recompute. |
| `CategoryProvider` | Category list CRUD. |
| `SettingsProvider` | User name, currency (symbol + locale), app locale (`Locale`). All persisted in Hive `settings` box. |

`TransactionProvider` and `ReportsProvider` are wired together manually in `main()`:
```dart
txProvider.reportsProvider = reportsProvider;
```

### Models

`Transaction` and `Category` use **Freezed** (immutable value objects) + **Hive CE** adapters generated by `build_runner`. `HiveField` indices and `HiveType` typeIds are locked — never renumber them, as that breaks existing user data:
- `TransactionType` enum: typeId 1
- `Transaction`: typeId 0
- `Category`: typeId 2

The six default categories (`Food`, `Transport`, `Salary`, `Shopping`, `Health`, `Other`) are seeded from `lib/data/models/default_categories.dart` on first launch and after "Clear all data". Their fixed IDs (`cat_food`, etc.) prevent duplication.

### Localization

The app uses Flutter's ARB-based gen-l10n. Config lives in `l10n.yaml` (root). Generated files live in `lib/l10n/` (not the synthetic `flutter_gen` path).

- Add/edit strings only in `lib/l10n/app_en.arb` (template) and `lib/l10n/app_ru.arb`.
- Run `flutter gen-l10n` after any ARB change.
- Import: `import 'package:expense_tracker/l10n/app_localizations.dart';`
- Access: `final l10n = AppLocalizations.of(context);` — non-nullable (configured with `nullable-getter: false`).
- The app locale is driven by `SettingsProvider.locale` (persisted in Hive under key `'locale'`, default `'ru'`).
- `MaterialApp` is wrapped in `Consumer<SettingsProvider>` so locale changes rebuild the entire app.

### Currency

Currency is stored as two independent strings in `SettingsProvider`: `currencySymbol` (e.g. `'₸'`) and `currencyLocale` (e.g. `'ru_RU'`). These are separate from the UI language locale. `Formatters.formatCurrencyWith()` uses `intl` `NumberFormat.currency` with these values. The supported currencies list lives in `settings_screen.dart` as `_currencies` const.

### Navigation

Single-page `IndexedStack` inside `AppShell` (no router library). Bottom `NavigationBar` controls the index. The four top-level screens are `const` instances that stay alive.

### Hive keys used in the settings box

| Key | Type | Default |
|---|---|---|
| `userName` | String | `''` |
| `currencySymbol` | String | `'₸'` |
| `currencyLocale` | String | `'ru_RU'` |
| `locale` | String | `'ru'` |

### CSV export

`ExportService` writes a UTF-8 BOM CSV to `getApplicationDocumentsDirectory()` and returns the `File`. The file is shared via `share_plus`. CSV headers are currently hardcoded in Russian — they are not routed through the localization system.

### Code generation

Any change to a `@freezed` class, a `@HiveType`/`@HiveField` annotation, or an `@injectable`/`@lazySingleton` annotation requires running `build_runner`. Generated files (`*.freezed.dart`, `*.g.dart`, `injection.config.dart`) are committed to version control.
